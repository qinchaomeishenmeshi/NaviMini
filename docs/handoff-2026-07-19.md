## 1. 当前目标与边界

NaviMini 是个人 Navidrome/Subsonic 的 **iOS 轻量播放器**（SwiftUI）。

- **成功标准：** 浏览列表 → 点歌 → 后台/锁屏控制，主路径稳定可预期  
- **不做：** 花哨流媒体 UI、复杂自动回退、完整媒体库（专辑/搜索等仍属后续）

权威上下文（必读）：

| 文件 | 作用 |
|------|------|
| [`PRODUCT.md`](../PRODUCT.md) | 产品定位：register=`product`，platform=`ios` |
| [`DESIGN.md`](../DESIGN.md) | 视觉系统：Clear Control Deck，系统 tint + SF |
| [`AGENTS.md`](../AGENTS.md) | 架构与技术方案；§9 指向上述两份 |
| [`.impeccable/design.json`](../.impeccable/design.json) | 设计 token sidecar |

North Star：**The Clear Control Deck**（清晰、直接、实用）

1. **真机验证**  
   冷启动加载、空库、断网 + 重新加载、锁屏切歌时列表是否只在离屏滚动、工具栏曲名是否更新。

2. **（可选）再跑 critique**  
   ```text
   $impeccable critique LibraryView
   ```  
   预期：P3 曲名已合入，Recognition / Visibility 可能再涨一点。

3. **仍开放的 polish（非阻塞）**
   - 用户主动滚离当前曲后，无「定位到当前」入口（可让工具栏曲名轻点 `scrollTo`）
   - 首刷总数探测时间长时，进度文案仍不可分阶段
   - 「正在播放」按钮样式仍是 `.bordered`（与 DESIGN Capsule 略有差异，非必须改）

4. **产品债（架构层，见 AGENTS §8）**
   ```text
   $impeccable shape 登录/配置页
   ```
   然后才是搜索 / 专辑 / 收藏等。

5. **播放页加深**

## 6. 注意

- 正式 UI **不要**回写 `ScreenshotShowcaseView` 里的蓝青靛渐变封面（DESIGN Don’t）。
- 颜色优先系统语义色（`accentColor` / `primary` / `secondary`），不要硬编码第二套品牌色。
- live / detect 浏览器链路对原生 SwiftUI **不适用**；critique 的 detector 对 `.swift` 常返回 `[]`，不能当「无问题」证明。
